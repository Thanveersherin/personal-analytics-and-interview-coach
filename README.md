# Personal Analytics & AI Interview Coach

Two data science and AI projects in one repository.

## Project 1: Personal Sleep & Productivity Analytics
Analyzing my own daily habits (sleep, study time, screen time, mood) with EDA, statistical tests, and a predictive model, shown in a dashboard.

## Project 2: AI Interview Coach
An LLM-powered app that generates interview questions from a job description and gives feedback and scores on my answers.
